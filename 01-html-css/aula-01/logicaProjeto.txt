Problema: Criar uma página que tenha uma lista de tarefas, onde o usuário precisa conseguir adicionar uma tarefa nova e depois
marcar como concluída

passo 1: Criar em HTML uma estrutura básica com todos os elementos necessários pra gerar uma estrutura simples
tipo ter um espaço pra onde as tarefas aparecerão, botões de adicionar, excluir, ou concluir tarefas.

passo 2: estilizar minimamente a pagina em CSS para que seja mais fluida e bonita.

passo 3: realizar a configuração da lógica funcional da página na qual adiciona novas tarefas ao apertar o botão "nova tarefa" e permita
o usuário digitar o NOME da tarefa, o PRAZO, e o nível de URGENCIA

Tarefas: Na tarefa temos "nome", "descrição", "prazo", "nível urgencia", "concluida: sim/não"

usuário clica em adicionar tarefa, uma tela aparece com os campos a serem preenchidos, com os valores solicitados acima, tirando a parte
onde o usuário define se está concluida ou não.

usuário preenche todos os campos e clica em finalizar, nisso o sistema deve pegar esses dados e apresentar eles em uma lista de tarefas em andamento

nessa mesma lista o usuario tem o poder de selecionar se a mesma foi concluida ou não, nisso a tarefa ficará marcada em outra lista "tarefas concluidas"

se o usuário quiser excluir a tarefa, poderá apertar no botão editar tarefa, e remover, assim a tarefa sairia da lista de tarefas em andamento

se o usuário criar uma tarefa sem nome, o sistema apresentará o erro de que um nome deve ser atribuido, isso só aconteceria para o nome e prazo da tarefa

imaginemos o seguinte: o usuário tem 3 tarefas "estudar HTML" "estudar CSS" e "estudar JS", e nisso o usuário precisa realizar três ações:
primeira ação > editar a tarefa "estudar CSS" para concluida
segunda ação > mudar o tipo de urgência da tarefa "estudar JS"
terceira ação> excluir a tarefa "estudar HTML"
como ele faria?

Primeiramente ele clicaria no botão editar tarefa na lista de tarefas em andamento, na tarefa "estudar CSS"
Depois ele localizaria o marcador "Concluida", deixaria o marcador selecionado, e salvaria a alteração
Nisso o sistema criará uma nova lista ao lado com o título "tarefas concluidas" e adicionaria as informações da tarefa "estudar CSS" lá
com isso concluímos a primeira ação

Segunda ação: usuário clica em editar tarefa, na tarefa "estudar JS", muda o seletor de urgência para "Alta" e salva a alteração
Nisso o sistema irá mudar o valor da urgência e apresentará na lista de tarefas em andamento o novo valor do campo urgência.
Com isso concluimos a segunda ação

Terceira ação: usuário clica em editar tarefa na tarefa "estudar HTML", localiza o botão "Excluir", clica nele, o sistema apresentará
uma mensagem de confirmação onde tem os botões "excluir" e "cancelar", usuário seleciona "excluir" e a tarefa simplesmente sai da lista
"tarefas em andamento"

Cada tarefa terá um indicador ao ser criada, começando pelo valor "0", no qual há sempre um incremento no momento de uma adição de nova tarefa
juntamente de todos os dados de cada tarefa também, por exemplo:

Tarefa 0
id_tarefa: 0
nome_tarefa: "X"
descricao: "X"
prazo: "X"
concluida: nao

e depois

Tarefa 1
id_tarefa: 1
nome_tarefa: "X"
descricao: "X"
prazo: "X"
urgencia: "X"
concluida: nao

o sistema guardará essas informações em um txt de consulta onde ele salva e verifica os valores das tarefas

as tarefas aparecerão na tela a partir das listas já existentes, serão duas, "tarefas pendentes" e "tarefas concluidas"

não serão automaticamente criadas novas tarefas assim que alguma for concluída, isso ficará de decisão do usuário

eu diria que o txt ficará salvo dentro do diretório do projeto com todas as informações gravadas, e poderão ser acessadas
novamente em outro momento, diria também que para não ter conflito com o id_tarefa, o sistema irá ler a quantidade de
ids existente, e assim irá encontrar o maior id gerado, gerando um incremento a partir do valor do maior id_tarefa

Como inicia o sistema?

Usuário entra na página de tarefas

sistema lê a base de dados que é o nosso .txt, SE tiver algo registrado, sistema apresenta as tarefas do usuário conforme já haviam
sido registradas, SE NÂO, sistema cria um txt para usar de base de dados

Se sistema encontrar .txt
    apresentar lista de tarefas salvas dentro do .txt ao usuário
    aguardar ação usuário
Se não
    criar txt em branco
    aguardar ação Usuário

Se usuario criar nova tarefa
    registrar nova tarefa em .txt
Se não
    aguardar ação do usuário 

Se usuário excluir tarefa
    sistema localiza o id_tarefa no txt, e exclui as informações
    sistema atualiza a interface com a nova informação de que uma tarefa de id X foi excluida
Se não
    sistema aguarda ação

Se usuário concluir tarefa
    sistema aloca tarefa na lista de tarefas concluídas
    sistema bloqueia qualquer edição em tarefas concluídas
Se não
    sistema aguarda ação

Se usuário tentar editar uma tarefa
    sistema verifica se a mesma está concluída ou não
        Se não concluída
            permitir edição
        Se estiver concluída
            bloquear edição

Sistema bloqueia totalmente edição de tarefas concluídas para que elas sempre fiquem a mostra na lista de tarefas já finalizadas

é possível que o usuário exclua tarefas concluídas caso o mesmo queira remover o registro da lista de concluidas
